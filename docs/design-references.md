# Public Experience Design References

The ClinicOCR public experience uses original application code and a clinical visual system informed by the following references requested by the project owner:

- [Animate UI](https://github.com/imskyleen/animate-ui) — a React, TypeScript, Tailwind, and Motion component distribution. Its motion-first component approach informed the staggered reveals, floating UI chips, and restrained interface transitions.
- [Inspira UI](https://github.com/unovue/inspira-ui) — a collection of configurable UI components. Its layered visual presentation and reusable section patterns informed the public Hero, About, and Sign-in layout.

No code or assets were copied from either repository. ClinicOCR keeps its own typography, clinical-evidence visual language, and review-first product behavior.
